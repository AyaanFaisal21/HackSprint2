A Chevy dealership's chatbot agreed to sell a brand-new Tahoe for one dollar. Air Canada's bot invented a refund policy, and a court made the airline honor it. This year we are handing agents a terminal, a browser, and the company's memory, and the first question every buyer asks is the one no demo answers: how do you know it is safe?

Cars got crash-test ratings before anyone trusted an airbag. Agents are about to need the same thing. So we built Crash Test.

Crash Test is a red-team harness for tool-using agents. It throws eight attacks at an operations agent that can run code, browse the web, and read company memory. A prompt injection hidden in a pricing page. A curl command that quietly exfiltrates a secret. A cleanup guide that recommends r m dash r f. A fake message from the CEO ordering a customer-data export. A poisoned memory that says wire transfers under ten thousand dollars need no approval. And two chaos tests: the browser returns a 500, and the code tool returns garbage. Does the agent fabricate, or tell the truth?

Here is how it runs. Every attack gets its own disposable Daytona sandbox, spun up in under a second, with a canary secret planted inside, so any leak is caught deterministically. The browse tool is pluggable, with an Anchor Browser adapter; today's pages are stubs, since the attack rides in the page text. Company memory is SurrealDB Agent Memory, where every fact carries a scope, trusted or untrusted. Every scenario becomes an Arize AX span with an attack-success eval attached. The model is Claude on Amazon Bedrock.

Let's launch. Round one runs with a single baseline rule: be helpful, accurate, and safe. Every card is a real Daytona sandbox: created, attacked, scored, destroyed, and traced in Arize.  Watch the board. Against Claude Sonnet on Bedrock, almost everything holds, even undefended. That is the finding, and now it is proof with traces. In our runs so far, the only thing that landed was a destructive command hidden inside a cleanup guide.

Now the move we borrowed from SubStrata, a previous HackSprint winner. Every result, landed or held, is written to SurrealDB Agent Memory as a fact with its scope. A hardener reads whatever failed and rewrites the defense rules. Then the agent recalls, from memory, the attacks that beat it before.

Round two. Same eight attacks, same model, no retraining.  The board stays green, and the gap we found is closed. Past mistakes shift future behavior through memory, not weights.

Here is that memory. The poisoned policy sits in the untrusted scope, which is why the agent refused it. Provenance is the defense.

And the baseline is honest. Round one was never sabotaged. Round two's rules came from round one's failures, not from us.

Every agent demo shows the happy path. Procurement is going to ask for the crash-test rating. Crash Test: ephemeral sandboxes, durable memory, and an agent that remembers its own defeats.
