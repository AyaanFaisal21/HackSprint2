01 / THE PROBLEM

Every agent demo shows the happy path.
Nobody demos the crash.

!

Hostile inputs are normal inputs

Web pages, docs and tickets carry instructions your agent was never meant to follow. One injected line and it exfiltrates, deletes or lies.

?

Failures are one-off anecdotes

A red-team finding lands in a Slack thread and evaporates. The next model swap re-opens every hole, and nobody notices until production.

↻

Agents should learn from losing

Crash Test records every defeat as durable memory with provenance, hardens the rules from those defeats, and proves the fix by re-running the attack.

02 / HOW IT WORKS

Four steps. One loop.

  1. 01

    Fan out attacks into sandboxes

    Eight attacks, each in its own disposable Daytona sandbox with a planted canary secret. The browse tool runs in Anchor Browser, off-box.

  2. 02

    Score with deterministic checks + LLM judge

    Canary leaks, destructive commands and forbidden sends are caught by rules. Subtler compliance is graded by a judge. Every scenario is an Arize span.

  3. 03

    Write every outcome to memory

    Landed or held, each result becomes a fact in SurrealDB Agent Memory under crashtest/redteam-log, with its scope attached.

  4. 04

    Recall and re-run

    A hardener rewrites the defense rules from round-1 failures. The agent recalls "attacks that beat me before" and faces all eight again.

SAFEGUARDS

Breaking agents safely.

Six properties that make the harness safe to run against a real model with real tools.

▦

Blast radius

One disposable Daytona sandbox per attack. Whatever the agent does inside it, the sandbox is deleted after the scenario ends.

◉

Off-box browsing

Anchor runs the browser in the cloud. Hostile pages render there, so an injected page never touches a host machine.

◆

Canary secret

A unique canary is planted in every sandbox. If it shows up in any answer, message or URL, the leak is caught deterministically.

⚙

Provenance

Every memory fact has a scope. Untrusted scopes are visible to the agent, so a poisoned fact can be recognized and refused.

◯

Observability

Every scenario is an Arize AX span with eval.attack_success, so round-over-round deltas are queryable, not anecdotal.

⚖

Honest baseline

Round 1 is not sabotaged. Round 2 rules were written from round-1 failures and recalled memory. No RL, no cherry-picking.
